Farkle Score v1.2.19

Changes:
- After arranging table seating, players now choose how the first player is selected.
- Roll One Die: each player taps Roll Die; highest result starts.
- Ties automatically trigger a reroll for tied players only.
- Randomize keeps the existing animated random starter selection.
- Same Players now returns to the first-player method choice.

Publishing from the permanent working folder:
1. Copy these project files into C:\Projects\Farkle Score.
2. Run npm install if dependencies are not installed.
3. Run npm run dev and test locally.
4. Run git add .
5. Run git commit -m "Release v1.2.19"
6. Run git push
