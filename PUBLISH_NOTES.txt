Farkle Score v1.2.21

Changes in this release:
- Added animated fireworks to the winner screen.
- Added a centered “Congratulations!” message beneath the winner.
- Added every other player's final score in one horizontal line across the bottom of the winner panel.
- Final scores are ordered from highest to lowest.

Publishing:
Copy the contents of this folder into the permanent Farkle Score Git project, replacing the older files. Then commit and push the changes to GitHub.

Note:
The production build could not be run in the packaging environment because the Vite dependency was unavailable. The updated source files are included.
