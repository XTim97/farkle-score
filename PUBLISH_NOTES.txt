Farkle Score v1.3.0

New in this release:
- Persistent career statistics for every saved player
- Game statistics on the winner screen
- Head-to-head records between players
- Achievement badges and milestones
- Player Statistics button on the Home screen
- Pink New Player button on the Pick Players screen
- Includes the improved iPad scoring-button touch response from v1.2.22

Before publishing:
1. npm.cmd install
2. npm.cmd run build
3. npm.cmd run dev
4. Test a complete game and confirm statistics appear after the winner screen.
